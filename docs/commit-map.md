author and committer fields. That changes the commit hash, so the short
hashes quoted inside the preregistrations and readouts in `docs/` do not
resolve in this history.

Those documents were not edited. Each was written and committed before the
run it governs, and that is what they are offered as evidence of; editing
their bodies to repair the hashes would have edited the artifact. This file
is the bridge instead, and it is generated by the same script that performs
the rewrite, so it cannot drift from it.
